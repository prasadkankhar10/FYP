HOW TO RUN:
--------------------------------------------------------------------------------
1. Double-click "SynapseFlow.exe".
2. The application will immediately launch in its own native desktop window.
3. No Python, Node.js, npm, or terminal commands are required!

--------------------------------------------------------------------------------
OFFLINE & DATABASE DETAILS:
--------------------------------------------------------------------------------
- The local SQLite database ("arsps.db") is bundled directly into the executable.
- The 3D Knowledge Graph, FSRS review scheduler, and Monaco coding challenges 
  run 100% locally and offline.
- If you have an internet connection and want live cloud AI code grading, 
  simply place a ".env" file in this folder with your GEMINI_API_KEY or GROQ_API_KEY.
